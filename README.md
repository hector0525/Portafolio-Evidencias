# Portafolio de evidencias — Héctor Antonio Bermúdez Tapia

Sitio web personal que presenta información académica, tecnologías, bases de datos y tres proyectos.

## Publicar con GitHub Pages
1. Abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama **main** y la carpeta **/(root)**.
4. Guarda. Cuando finalice el despliegue, consulta la URL que GitHub Pages muestra en esa sección.

## Fotografía
La página utiliza `assets/foto-perfil.jpg`; conserva esa ruta para mostrar la fotografía en la portada.

## Antes de entregar
- Comprueba que la fotografía se visualiza.
- Revisa que las tecnologías reflejen tu nivel real de dominio.
- Agrega capturas propias de los proyectos y evidencias de pruebas.
- Verifica que los repositorios de equipo se puedan compartir públicamente.
